# X 书签文件夹（第三方）

X（Twitter）的书签文件夹要开 X Premium 才能用。这个油猴脚本在本地实现了一套书签文件夹，电脑端和手机端网页都能用，还可以通过 WebDAV 在不同浏览器之间同步。

## 安装

1. 安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
   - 新版 Chrome / Edge 需要在扩展详情页打开「允许运行用户脚本」，部分版本还要打开「开发者模式」，否则脚本不会运行。
2. 点击安装：[x-bookmark-folders.user.js](https://raw.githubusercontent.com/exynos967/x-bookmark-folders/main/x-bookmark-folders.user.js)
3. 打开 <https://x.com/>，刷新页面。

脚本带有 `@updateURL`，推送新版本后脚本管理器会自动提示更新。

## 功能

- **入口**
  - 电脑端：左侧栏「Money」下方的「书签文件夹」。
  - 手机端：点头像打开的抽屉菜单里，「Money」下方。
  - 账号没有 Money 入口时，依次挂在 Premium、历史、书签下方。
- **收藏到文件夹**：每条帖子「分享」按钮右侧有一个文件夹按钮，点开后勾选放进哪些文件夹（可多选），也能当场新建。已收藏的帖子按钮显示为蓝色实心。
- **管理面板**：「全部收藏」和各个文件夹；新建、重命名、删除文件夹，移出帖子；点帖子在站内跳转。
- **设置**（面板右上角 ⚙）
  - WebDAV 云端同步：文件夹地址、用户名、密码，「测试连接」「立即同步」。
  - 自动同步：修改收藏后约 30 秒同步一次，期间的多次修改合并为一次；没来得及同步的修改会在下次打开页面时补上。
  - 本地备份：导出 / 导入 JSON（导入是合并，不会覆盖现有数据）。
- 同时适配 X 的两套网页客户端（新版 x-web 和旧版 responsive-web），界面语言为中文时显示中文，否则显示英文。

## WebDAV 同步

- 数据保存为你填写的文件夹下的 `x-bookmark-folders.json`；文件夹不存在时会自动创建（只创建最后一级）。
- 坚果云示例地址：`https://dav.jianguoyun.com/dav/x-bookmarks/`，密码填「第三方应用密码」。
- 第一次同步时脚本管理器会询问是否允许访问该域名，选「总是允许」。
- 同步是**合并**而不是覆盖：每次先下载云端数据与本地合并再上传，多个浏览器各自的修改都会保留。删除会留下带时间戳的记录（保留 180 天），不会被另一端同步回来。
- 自动同步只在本地修改后触发。想立刻拿到另一台设备的改动，点「立即同步」。

## 数据与安全

- 收藏数据只保存在本浏览器的脚本存储里；开启 WebDAV 后，才会上传到你自己的网盘。
- WebDAV 密码用 AES-GCM 256 位加密后保存。密钥是浏览器生成的不可导出密钥，存放在 x.com 的 IndexedDB 中，脚本存储里只有密文。
  - 能同时读取这两处存储的人（例如本机恶意程序）仍然可以解密。建议使用网盘的应用专用密码，泄露后可以在网盘后台撤销。
  - 清除 x.com 的网站数据会删掉密钥，此时重新输入一次密码即可。
- 脚本使用 `GM_xmlhttpRequest` 并声明了 `@connect *`，因为 WebDAV 地址由用户自定义；它只会请求你填写的地址。

## 已知限制

- 收藏保存的是帖子快照（作者、正文前 500 字、头像和首张图片地址），原帖删除后快照仍在，但点进去会显示帖子不存在。
- X 的页面结构经常变动，如果按钮或入口消失，欢迎提 Issue，并附上浏览器、脚本版本（控制台执行 `document.documentElement.dataset.xbf`）和截图。
